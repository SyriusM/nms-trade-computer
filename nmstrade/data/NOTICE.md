# Data sources

- `mapping.json`: save-file key mapping from MBINCompiler release v7.10.0-pre1
  (https://github.com/monkeyman192/MBINCompiler), distributed under the GNU LGPL.
  Replace it with a newer release asset after major game updates.
- `gamedata.json`: trade goods (IDs, names, base values, price modifiers) and the in-game
  names of economy, wealth and conflict levels, extracted from No Man's Sky game data dumps
  (NMSE `Resources/json/Trade.json` and the en-GB language table). Polish economy names from
  the game's localisation as published in nms-galaxy-navigator (MIT).

No Man's Sky is a trademark of Hello Games. This tool is unofficial and only reads save files.
